# The Bad Software Company - Implementation

Source: https://badsoftware.com/implementation.html

Summary: Hands-on engineering that turns assessed problems and prioritized recommendations into working software and maintainable systems.

Turn the plan into working changes.

Implementation is a standalone service. It can begin with a defined project or carry selected recommendations into documentation, API contracts, SDKs and integrations, automated tests, test infrastructure, observability, prototypes, internal tools, and customer-facing applications.

The Mailinator work moved through this full loop: investigation revealed connected documentation and product problems, an OpenAPI specification established a source of truth, and four SDKs were brought back into alignment.
